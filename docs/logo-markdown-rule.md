# Logo Markdown Rule

Use the GitHub Raw URL when you need the logo in Markdown:

```md
![J-T LOGO RED](https://raw.githubusercontent.com/Henry9396/PE-/main/assets/logo/jt-logo-red.svg)
```

Rules:

- Use SVG first for crisp rendering.
- Use PNG only if a target system does not support SVG.
- Keep the `alt` text short and descriptive.
- Prefer stable GitHub Raw links over local file paths.
