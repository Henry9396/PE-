# Logo Markdown Rule

Use the GitHub Raw URL when you need the logo in Markdown or email signatures.

For email signatures, use the smaller variant:

```html
<img src="https://raw.githubusercontent.com/Henry9396/PE-/main/assets/logo/jt-logo-red-signature.svg" width="180" alt="J-T LOGO RED">
```

Rules:

- Use SVG first for crisp rendering.
- Keep the `alt` text short and descriptive.
- For email signatures, prefer the `jt-logo-red-signature.svg` variant with a fixed width.
- If a target system does not support SVG, convert the same artwork to PNG and keep the width around 180 px.
- Prefer stable GitHub Raw links over local file paths.
